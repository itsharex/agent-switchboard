# Skill 与 MCP 管理后续执行方案

日期：2026-09-06。目标：完成已批准的 Skill 与 MCP 管理设计，保持单一当前契约、单一真实配置写入层、显式预览确认和可恢复事务。

## 总体顺序

先完成资源编辑与接管的正确性，再扩展多资源部署能力，最后进行真实客户端和跨平台验收。每个批次在前一批的测试通过、旧入口删除、文档更新后才开始下一批。

## 批次一：已有 MCP 的安全编辑

目标是让 stdio、HTTP、Claude SSE、Claude WebSocket 定义都能编辑，不把原有明文、URL 或凭据回传给界面。

契约由 core extensions 拥有。新增字段级编辑请求：每个字段只能显式保留、替换或删除；保留只允许引用当前定义中已有的值，替换的敏感值先进入系统凭据存储。编辑请求必须携带当前 revision，并在后端合成为完整定义后执行统一校验。

桌面命令只接受该编辑请求，保存后使关联的启用绑定进入待部署状态。页面以脱敏视图展示当前值，支持修改字段、修改服务键和选择 Claude 专用传输。服务键变更必须在同一计划中检查所有目标的原生键冲突。

验收包括：保留未展示的敏感字段、替换或删除每种字段、revision 冲突、跨客户端传输拒绝、未知原生字段保留、编辑后预览再部署、失败回滚和日志脱敏。旧的全量保存草稿入口在直接消费者切换后删除。

## 批次二：Skill 创建、本地副本和依赖

新增受限的本地 Skill 工作区。用户可从模板创建或把库中内容复制为本地副本；编辑器只处理静态文件，不执行脚本、动态命令或安装钩子。每次保存生成新的不可变内容摘要，原版本继续可恢复。

Skill 依赖改为真实关系：依赖 MCP 必须引用库定义，页面展示每个目标的可用、待配置或不支持状态。用户选择后由同一预览产生 Skill 与依赖 MCP 的组合部署，不自动安装依赖。

验收包括：frontmatter 和路径校验、内容版本不变性、文件修改和外部改动检测、依赖缺失或不支持的拒绝、组合计划的全量回滚，以及旧版本恢复。

## 批次三：统一多资源计划、批量部署和固定版本

把单资源计划收敛为一份批量计划：计划由一组有类型的资源操作组成，每项仍有定义 revision、目标、文件前置条件和凭据摘要。单资源操作也通过同一结构表达，现有单资源请求和重复的计划形状一并删除。

批量操作支持多目标安装、更新、启停、移除、依赖组合部署和按绑定固定内容摘要。计划预览按资源和目标分组，但确认、锁获取、journal、库提交与回滚只有一个事务边界。

验收包括：同一文档多项补丁、跨资源冲突、第二项失败回滚全部前项、同目标锁互斥、固定版本后来源更新不影响目标、批量恢复指定历史操作。

## 批次四：导入、接管和便携包

导入保持只复制到库。新增独立的接管操作，只允许完整可表达且与目标文件逐字段等价的本机项：接管预览记录原生条目或目录的原始基线和当前摘要，但不在确认前写客户端文件。

接管后，移除绑定必须恢复接管前的原始状态；有未知字段、同名冲突、外部改动、项目根漂移或无法证明等价时拒绝接管。绝不把导入按钮改成隐式接管。

便携导出只包含不可变 Skill 内容、定义、非敏感来源身份和凭据引用占位符；导入后要求用户重新绑定本机凭据。导出不含任何真实客户端文档、URL、明文参数、密钥或备份。

验收包括：接管和移除的完整往返、所有拒绝条件、离线包摘要与路径校验、凭据占位符重绑定和跨设备导入后预览。

## 批次五：真实客户端与平台验收

建立隔离夹具：临时 HOME、临时 Codex 根、临时 Claude 根、临时项目根和专用进程环境。夹具不读取用户真实配置、不写注册表、不复用用户凭据。

按明确支持的 Codex 与 Claude Code 发行版验证：Skill 发现和启停、用户/项目共享/项目私有 MCP、Claude 自定义配置根、SSE/WS 限制、原生重载提示。未验证的能力继续由能力表拒绝写入。

在 Windows、macOS、Linux 验证目录权限、占用、Unicode、长路径、符号链接、跨盘替换、进程崩溃和重启恢复。用本地假 MCP 服务验证 stdio、HTTP、SSE、WS 的认证失败、分页、超时、取消、输出上限和子进程清理。

## 契约升级规则

持久化形状变更时先运行一次性离线迁移：完整读取旧状态、验证业务含义、写入新状态到临时位置、回读验证、原子替换。运行时只接受一个 schema，不保留双读、双写、默认补字段或回退解析。

有未完成扩展事务时迁移必须拒绝，先恢复或清理已持久化提交的 journal。计划缓存只在进程内存在，应用升级后直接失效并要求重新预览。

## 最终发布门槛

完成条件不是页面有入口，而是每个声称支持的操作都具备：唯一类型契约、后端命令、计划预览、确认后的事务执行、可恢复历史、前端结果、失败测试和真实环境证据。

发布前运行扩展核心、switch 事务、桌面命令、前端流程和全工作区测试；完成支持平台的 release 构建与安装包验证；扫描输出、计划、日志、备份和导出物确认不存在真实密钥或私有地址。任何未核实能力保持门禁，不能以说明文字替代。
