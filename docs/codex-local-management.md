# Codex 本地管理实现

## 范围与入口

本轮补的是 Codex 后端链路及可操作入口，不移植 CC Switch 的页面。原供应商页、Codex 编辑器、通用文件可视化控件及样式令牌保留。补充入口为：**设置 → 诊断 → 配置与环境 → 管理 Codex 功能**。

该弹窗分为供应商、认证、通用配置、网关与 Failover、计量、指令预设。MCP/Skills 仍归原扩展工作区，不新增第二个内容库或写配置路径。

## 唯一所有者

路径相对应用的 `state/`，不是仓库目录：

| 数据 | 所有者 / 文件 |
| --- | --- |
| Codex 第三方档案 | 原 `configuration/providers/codex/` 专用契约；不进入 Claude 的档案业务 |
| 官方档案元信息 | 原 Codex 官方记录；托管令牌不放进供应商档案 |
| 可视化通用配置 | 原 `configuration/client-settings/codex.json` |
| 每档通用文件启停 | `codex/common-config-policy.json`；不复制设置值 |
| ChatGPT 账号、默认账号、绑定、令牌代际、待同步意图 | `codex/accounts.json`，后端私有；Unix 文件权限 0600 |
| 官方登录保留策略 | `codex/auth-policy.json` |
| 托管账号额度基线 | `codex/account-quota-history.json`；不与原生全局额度基线混用 |
| Codex 网关与 Failover | 原 `codex/gateway-policy.json`、独立健康状态 |
| 请求计量 | 原 `codex/requests.sqlite3` 和 Codex 计价设置 |
| 命名指令预设 | `codex/prompts.json` |
| 指令事务 | `codex/prompt-switch.json`；只在待提交/恢复时存在 |
| 原生 token 同步备份 | `codex/auth-backups/`；仅用于执行器恢复，不作为可移植账号导出 |

`codex_auth/`、`codex_prompts/`、`codex_common/`、`commands/status/codex.rs` 与 `validate/codex.rs` 独立实现 Codex 业务。通用 HTTP、文件原子写入、控件与同一个客户端写入闸门可以复用；Claude 的模型、托管账号及状态规则不参与 Codex 验证。

## 认证与同步

- 账号身份同时包含用户和工作区，不能只凭 workspace/account id 合并用户。
- 没有绑定时沿用原生登录；显式账号绑定不随默认账号变动。切换默认或修改绑定只保存意图，用户仍需预览并确认应用。
- 新增/定向重认证使用原生 Codex device flow。设备会话具有独立 nonce；旧轮询或迟到取消不能提交或取消新会话。
- 界面只收到账号元信息、状态、设备码和验证 URL，不收到 access/refresh/id token。默认账号、绑定、删除等修改有存储版本校验。
- 官方账号切换通过 `SwitchPlan` 的后端私有认证投影进入 `asb-switch`。认证源/结果哈希不可省略。配置与 auth 备份保持关联，恢复及撤销恢复仍能找到配对文件。
- 保存新一代托管 token 后，只有原生文件**仍共享该刷新令牌链且文件版本没有外改**时，才调用执行器同步原生 token。同步保留 API-key 模式、API key、路由和其他原生键；不把 API-key 会话改为 ChatGPT 会话。
- 同步失败会保存待重试意图和诊断；下一次请求可用已保存的新 token 重试，不重复轮换旧 refresh token。原生退出/切换到另一登录会脱离该同步关系，不能被旧请求复活。
- 恢复旧托管认证时校验代际及账号是否仍存在，不把已刷新、已删除账号的历史 token 写回去。

当前认证写入只支持默认文件存储或显式 `file`。`keyring`、`auto`、`ephemeral` 不会被悄悄改成 `file`，遇到需要写入/共享刷新链的操作会明确拒绝。独立的原生退出事务仍未对齐。

## 通用配置和指令

通用设置的提取只读取现有可视化目录中的客户端键。不会把供应商密钥、模型目录、MCP、项目覆盖或未知宿主字段固化到通用文件。每档停用时投影为现有“自动”值，不清空保存的通用意图。修改通用文件和应用到客户端是两个明确步骤，后者复用完整切换预览。

指令预设只写用户级 `AGENTS.md`，不写仓库 `AGENTS.md` 或 `CLAUDE.md`：

1. 新建/编辑非活动预设只改本地库。
2. 启用其他预设前回填 live 内容，空内容也被保留；首次覆盖前保留原文为预设并生成执行器备份。
3. 当前预设互斥；编辑活动预设、停用当前预设均需明确确认。
4. `AGENTS.md` 的锁、版本、备份、原子替换、校验与库提交在同一事务中；失败回滚不覆盖外改。
5. 启动后遗留事务可显式恢复。只清理已证实进程死亡的锁，不删除仍由活动进程持有或无法判断的锁。
6. 有待恢复预设事务时，原全局指令编辑器不能绕过它写入文件。

## 计量与功能边界

计量入口展示网关持久请求、分页/筛选/汇总、手动价格、倍率、预算与费用回填。未知价格保持“未计价”。本机会话统计仍是独立来源，当前不把它与网关账本相加冒充统一计量。

当前配置快照/云备份**不等于**新账号库、指令库和全部 Codex 策略的便携完整导出。不要把旧的供应商配置快照当作账号备份。

整个 CC Switch Codex 目标仍未收口。xAI OAuth、官方账号接管、非文件认证、全局出站代理、HTTP 跨请求续接的完整矩阵、统一历史/增量计量与跨源去重、项目 Profile、完整便携迁移等仍有缺口；以 [对齐账本](codex-ccswitch-parity.md) 为准，不因本入口可用就宣称完整复刻。

## 验证原则

所有写入测试使用隔离临时目录或模拟服务。仓库内 Codex CLI 通过隔离 `CODEX_HOME`、清空进程环境并只访问 loopback 服务验证无 ChatGPT 登录的网关调用。未使用真实 OAuth 账号、真实 API key、用户凭据缓存或付费上游进行写入测试。

最终运行命令和结果记在 `progress.md`；缺少真实服务或平台实测的项目不被列为完成。
